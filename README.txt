SOFTDAY — обновление календаря, событий и графика смен

1. Скачай и распакуй ZIP на компьютере.
2. В GitHub открой index.html → Edit (карандаш) → замени всё содержимое текстом из нового index.html → Commit changes.
3. Так же полностью замени script.js содержимым нового script.js → Commit changes.
4. Открой style.css → Edit → добавь содержимое style_additions.css в самый конец файла → Commit changes.
5. Открой сайт на iPhone и обнови страницу. Если старая версия осталась, закрой вкладку и открой сайт снова.

Что нового:
• В календаре события и смены отображаются розовыми прямоугольниками с названием и временем, а не цветными точками.
• При добавлении события можно указать время начала.
• У смен можно указать время начала и продолжительность.
• Время на карточках отображается в 12-часовом формате AM/PM.
• События без времени помечаются «Весь день».
• Сохраняются прежние данные в localStorage браузера; существующие события без времени остаются событиями на весь день.

В «График работы» сначала создай тип смены (название + ставка в час). Затем в календаре выбери день → «Добавить смену» → выбери тип, время начала и количество часов. Доход рассчитывается автоматически.
