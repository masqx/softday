softday — точечное обновление календаря

Что меняется:
- Сетка календаря и остальной дизайн остаются прежними.
- Событие/дело можно добавить с необязательным временем начала.
- Смена при добавлении в календарь получает время начала.
- В ячейках календаря отображаются только события с указанным временем (кроме домашки) и смены с указанным временем.
- События без времени и домашние задания остаются в списках, но не засоряют календарь.
- В календаре время показывается в 12-часовом формате, например 3:00 PM.
- Цвета событий и смен остаются в розовой гамме.

Установка:
1. Распакуй архив.
2. В GitHub открой index.html, нажми карандаш, замени всё содержимое на файл index.html из архива, затем Commit changes.
3. Аналогично полностью замени script.js.
4. Аналогично полностью замени style.css. Это полный файл стилей, не нужно ничего дописывать отдельно.
5. Открой сайт и обнови страницу. Если на iPhone показывается старая версия, закрой вкладку и открой сайт заново.

Данные сайта хранятся в localStorage браузера под прежним ключом softday-prototype-v1; этот код не меняет ключ хранения и не должен удалять сохранённые дела, смены или копилку.

Важно: для ранее созданных смен, у которых время начала ещё не сохранялось, время не придумывается — они остаются в списке смен, но в календарной сетке появятся только после добавления смены с указанным временем.
