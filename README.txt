SOFTDAY — обновление графика смен

1. В GitHub замените index.html на этот index.html.
2. Замените script.js на этот script.js.
3. Откройте style.css, нажмите Edit, добавьте содержимое style_additions.css в самый конец и сохраните (Commit changes).
4. Обновите сайт в Safari.

Теперь в «График работы» можно создать тип смены (название + ставка в час). В календаре выберите дату → «Добавить смену» → выберите тип и количество часов. Доход считается автоматически как часы × ставка.

Данные остаются в localStorage этого браузера. Существующие сохранённые данные не удаляются; если старые смены были в старом формате, они тоже должны отображаться.
